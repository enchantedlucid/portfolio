Information Technology Security (BITS3423) · Group 12 · Sem 2, 2025/2026 · Backend Developer
ALMS Secure Web — Attendance & Leave System

A security-hardened, web-based rebuild of the Attendance & Leave Management System, built for the IT Security group project (Group 12) with Wardina Najihah and Nurul Fatihah, under Ts. Dr. Zurina Binti Sa'aya. As backend developer, Fatnin migrated the original C++/MySQL desktop schema into a full PHP/MySQL web application — building the Register, Login, Dashboard, Attendance, and Leave Management modules — and implemented OWASP A01 (Broken Access Control) and A03 (Injection) controls across the codebase. The system runs across two isolated Ubuntu Server VMs: an Apache + PHP 8.2 web server reachable over HTTPS, and a MySQL 8.0 database server confined to a private Host-Only network with zero public internet exposure, enforced by UFW.

My Role — Application Layer
  • Register, Login, Dashboard modules
  • Attendance & Leave modules
  • C++ → web schema migration
  • Session checks (A01) & prepared queries (A03)
Security Controls (OWASP)
  • bcrypt password hashing (A02)
  • HTTPS enforced, TLS 1.2/1.3
  • HttpOnly/Secure/SameSite cookies (A07)
  • htmlspecialchars() output encoding (A03 XSS)
Infrastructure (Team)
  • Two-VM: Apache web server + isolated MySQL server
  • UFW — DB port restricted to web server IP
  • Self-signed SSL cert
  • SFTP chroot jail
